
This repository is a collection of hands-on networking labs built in Cisco Packet Tracer while studying Computer Networks (CNC601400) at Superior University Lahore. Each .pkt file is a self-contained topology exploring a specific concept  from basic device connectivity to dynamic routing protocols and network security fundamentals.

Labs included:

What it covers
1	01-basic-topology-hubs-switches-routers.pkt	3× Router 2911, 4× Switch 2960, 2× hubs, 20 hosts — foundational topology showing how routers, switches and hubs interact, and where collision domains form
2	02-campus-network-design.pkt	Campus-style network design
3	03-eigrp-routing.pkt	EIGRP dynamic routing configuration
4	04-department-network-segmentation.pkt	Single Router 2911 with a private addressing scheme serving 3 departments (Finance, IT, HR), each behind its own switch
5	05-ospf-routing.pkt	OSPF dynamic routing configuration
6	06-rip-routing.pkt	RIP dynamic routing configuration
7	07-static-nat-configuration.pkt	Static NAT — private-to-public address translation
8	08-home-task-2.pkt	Home assignment topology/config practice
9	09-troubleshooting-cdp-lldp.pkt	Diagnosing and troubleshooting using CDP/LLDP commands

Tools: Cisco Packet Tracer
How to open: Download any .pkt file and open with Cisco Packet Tracer (free for students via the Cisco Networking Academy).
